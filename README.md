# Мои расходы — учёт личных финансов

Простое веб-приложение для учёта расходов и контроля месячного бюджета.

Приложение создано на HTML, CSS и JavaScript. Работает в браузере и поддерживает установку на iPhone и MacBook как PWA.

## Что умеет приложение

### 1. Добавление расходов

Пользователь может записывать траты, указывая сумму, категорию, дату и комментарий.

Все расходы сохраняются в браузере с помощью localStorage.

Требования: [Добавление расходов](specs/001-dobavit-tratu.md).

### 2. Итоги по категориям

Приложение автоматически подсчитывает расходы текущего месяца по четырём категориям:

- Еда
- Транспорт
- Дом
- Другое

Требования: [Итоги по категориям](specs/002-itogi-po-kategoriyam.md).

### 3. Удаление расходов

Пользователь может удалить ошибочно добавленную трату.

Перед удалением появляется подтверждение. После удаления общая сумма и итоги по категориям пересчитываются.

Требования: [Удаление расходов](specs/003-udalit-tratu.md).

### 4. Общий месячный бюджет

Пользователь может установить бюджет на текущий месяц.

Приложение показывает:

- Размер бюджета.
- Сумму расходов.
- Оставшиеся деньги.
- Процент использованного бюджета.

При превышении бюджета отображается предупреждение.

### 5. Бюджет по категориям — Урок 10

Для каждой категории можно установить отдельный месячный лимит.

Приложение показывает лимит, потраченную сумму, остаток и индикатор использования бюджета.

Если расходы превышают лимит, индикатор становится красным и появляется предупреждение с суммой перерасхода.

Требования и этапы разработки: [Бюджет по категориям](specs/004-byudzhet-po-kategoriyam.md).

### 6. Установка на iPhone и MacBook

Приложение поддерживает PWA.

На iPhone его можно добавить на главный экран через Safari, а на MacBook — добавить в Dock.

## Как проверить

1. Добавить три расходы за текущий месяц: Еда — 5 000 ₸, Транспорт — 2 500 ₸, Дом — 12 000 ₸.
2. Убедиться, что общий итог равен 19 500 ₸.
3. Установить месячный бюджет 50 000 ₸. Остаток должен составить 30 500 ₸.
4. Установить лимиты категорий: Еда — 10 000 ₸, Транспорт — 2 000 ₸, Дом — 20 000 ₸.
5. Проверить остаток категории «Еда»: 5 000 ₸.
6. Проверить предупреждение у «Транспорта»: перерасход 500 ₸.
7. Обновить страницу — данные должны сохраниться.
8. Удалить трату «Еда» на 5 000 ₸. Общий итог должен стать 14 500 ₸, а остаток общего бюджета — 35 500 ₸.

Проверки выполняются на тестовых данных. Если в браузере уже есть другие расходы текущего месяца, итоговые суммы будут отличаться.

## Правила разработки

Правила для AI-агента находятся в [AGENTS.md](AGENTS.md).

Каждая новая функция начинается с файла требований в папке `specs/`.

Большие функции разбиваются на небольшие шаги. Каждый шаг проверяется отдельно и сохраняется отдельным Git-коммитом.

Агент не должен выполнять коммит без подтверждения пользователя.

## Отчёт по Уроку 10

**Задача:** реализовать бюджет по категориям методом декомпозиции.

**Что сделано:**

1. Добавлена установка лимитов по категориям.
2. Добавлен расчёт потраченных сумм и остатков.
3. Добавлены индикаторы использования лимитов.
4. Добавлены предупреждения о перерасходе.
5. Проверена совместимость с существующими функциями.

**Результат:** большая функция разделена на пять проверяемых шагов. Каждый этап выполнялся последовательно, после проверки сохранялся отдельным коммитом.

**Вывод:** декомпозиция помогает проще проверять изменения, находить ошибки и сохранять рабочие версии приложения.

## Хранение данных

Расходы и бюджеты сохраняются локально в браузере с помощью localStorage.

Данные не синхронизируются автоматически между iPhone и MacBook. При очистке данных браузера записи могут быть потеряны.
