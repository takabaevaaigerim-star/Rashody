# Учёт расходов

Простое веб-приложение для учёта личных расходов. Позволяет записывать траты, отслеживать расходы по категориям и контролировать общую сумму за текущий месяц.

Приложение работает без регистрации и интернета. Данные сохраняются в браузере с помощью localStorage.

## Что умеет

**1. Добавление расходов**

Пользователь может добавить сумму, категорию, дату и комментарий. Новые расходы появляются сверху списка.

Требования к функции

**2. Итоги по категориям**

Приложение автоматически подсчитывает расходы за текущий месяц по категориям: Еда, Транспорт, Дом, Другое.

Требования к функции

**3. Удаление расходов**

Пользователь может удалить ошибочно добавленную трату. Перед удалением появляется подтверждение, после чего суммы пересчитываются.

Требования к функции

## Как открыть и проверить

1. Скачать проект с GitHub или открыть папку Rashody на компьютере.
2. Открыть файл `index.html` в браузере.
3. Добавить три траты с датой текущего месяца:
   - Еда — 5 000 ₸.
   - Транспорт — 2 500 ₸.
   - Дом — 12 000 ₸.
4. Проверить, что общий итог равен 19 500 ₸.
5. Обновить страницу — расходы должны сохраниться.
6. Удалить трату «Еда» на 5 000 ₸ и подтвердить удаление. Итог должен стать 14 500 ₸, а категория «Еда» — 0 ₸.
7. Проверить, что пустую или отрицательную сумму добавить нельзя.
8. Проверить страницу на телефоне шириной 375px.

## Правила для агента

Все правила находятся в [AGENTS.md](http://AGENTS.md).

Основные правила:

- Использовать HTML, CSS и JavaScript без библиотек.
- Хранить данные только в браузере.
- Показывать суммы в целых тенге с пробелами между тысячами.
- Не изменять уже работающие функции.
- Сначала создавать файл требований в `specs/`, затем реализовывать функцию после команды «Делай».

**Уточнённое правило:** если пользователь просит полный код файла, предоставлять его целиком, сохраняя все работающие функции.

## Отчёт

**Что получилось**

Созданы три основные функции приложения: добавление расходов, расчёт итогов по категориям и удаление расходов. Для каждой функции создан отдельный файл требований в папке `specs/`.

**Какое правило удалось соблюдать**

Денежные суммы отображаются в целых тенге с пробелами между тысячами. Данные сохраняются локально в браузере.

**Какая возникла проблема**

При ручном добавлении второй функции было неудобно искать отдельные участки кода для изменения. Поэтому возникла необходимость работать с полными версиями файлов.

Это была проблема ручного редактирования, а не подтверждённая ошибка AI-агента.

**Как уточнили правило**

В [AGENTS.md](http://AGENTS.md) добавлено правило: если пользователь просит полный файл, предоставлять его целиком и сохранять ранее работающие функции.

**Что осталось проверить**

После восстановления доступа к AI-агенту нужно отдельно проверить, как он соблюдает уточнённое правило в новом чате.
