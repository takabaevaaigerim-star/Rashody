# AGENTS.md — Учёт расходов

## О проекте

«Учёт расходов» — веб-приложение для контроля личных расходов за месяц. Пользователь может записывать траты, смотреть итоги и понимать, на что уходят деньги.

Приложение должно работать на компьютере и телефоне.

Файлы проекта:

- `index.html` — структура страницы.
- `styles.css` — оформление.
- `script.js` — логика приложения.
- `specs/` — требования к отдельным функциям.
- `README.md` — описание проекта для пользователя.

## Правила

- Используй только HTML, CSS и JavaScript, без npm, библиотек и внешних ресурсов.
- Все данные храни в браузере через localStorage. Ничего не отправляй в интернет.
- Интерфейс полностью на русском языке.
- Поля и кнопки должны быть не меньше 44px.
- Страница должна корректно работать на телефоне шириной 375px.
- Не изменяй уже работающие функции без необходимости.
- Деньги показывай в целых тенге с пробелами между тысячами: 15 000 ₸.
- Не допускай отображения NaN.
- Не сохраняй расходы с пустой, отрицательной или неверной суммой. Показывай понятную ошибку.
- После завершения функции обновляй README.md и объясняй, как проверить результат.
- Не запускай Git и не создавай коммиты самостоятельно. Сначала я проверяю работу, затем сохраняю изменения вручную.
- Если изменение затрагивает несколько частей одного файла, сначала перечисли точные места изменений. 
- Если пользователь просит полный файл, предоставь его целиком и сохрани все уже работающие функции.

## Новая функция

- Каждую новую функцию начинай с файла `specs/NNN-nazvanie.md`.
- Нумерация: 001, 002, 003 и далее.
- Названия файлов пиши латиницей, строчными буквами и через дефис.
- Каждый файл требований должен содержать разделы: «Для кого и зачем», «Что должно быть», «Примеры», «Ограничения», «Готово, когда».
- Сначала создай файл требований и дождись моей команды «Делай».
- Пока я не написал «Делай», программный код не изменяй.
- После реализации функции обнови README.md.

## Как проверить

- Открыть `index.html` в браузере.
- Добавить расходы: 5 000 ₸, 2 500 ₸ и 12 000 ₸.
- Проверить, что итог за месяц составляет 19 500 ₸.
- Обновить страницу — расходы должны сохраниться.
- Проверить, что пустую или неправильную сумму нельзя добавить.
- Проверить работу на экране шириной 375px.
