# Функция 003 — Удалить трату

## Для кого и зачем

Пользователь должен иметь возможность удалить ошибочно добавленный расход, чтобы история и итоги оставались правильными.

## Что должно быть

- Рядом с каждой тратой кнопка «Удалить».
- Перед удалением появляется окно подтверждения.
- При подтверждении удаляется только выбранная трата.
- Общий итог за текущий месяц и итоги по категориям пересчитываются автоматически.
- Изменения сохраняются в localStorage.
- После обновления страницы удалённая трата не возвращается.

## Примеры

| Действие                                               | Ожидаемый результат                        |
| ------------------------------------------------------ | ------------------------------------------ |
| Удалить трату «Еда» на 4 000 ₸ из общей суммы 84 000 ₸ | Общий итог 80 000 ₸, категория «Еда» — 0 ₸ |
| Удалить «Транспорт» на 50 000 ₸                        | Общий итог уменьшается на 50 000 ₸         |
| Нажать «Отмена» в подтверждении                        | Ничего не удаляется                        |
| Обновить страницу после удаления                       | Удалённая трата не появляется              |
| Удалить последнюю трату                                | Появляется «Пока нет расходов», итог 0 ₸   |

## Ограничения

- Не менять работающие функции добавления расходов и расчёта по категориям.
- Использовать только HTML, CSS и JavaScript.
- Не использовать библиотеки.
- Не удалять другие записи при удалении одной.
- Не показывать NaN.
- Сохранять данные только в браузере.
- Не запускать Git автоматически.

## Готово, когда

- У каждой записи есть кнопка «Удалить».
- Удаляется только выбранная запись после подтверждения.
- При отмене ничего не меняется.
- Общий итог и категории обновляются сразу.
- После обновления страницы удалённая запись не возвращается.
- Удаление удобно работает на телефоне шириной 375px.
