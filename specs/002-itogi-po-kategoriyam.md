# Функция 002 — Итоги по категориям

## Для кого и зачем

Пользователь хочет понимать, на какие категории уходит больше всего денег за текущий месяц.

## Что должно быть

- Под общим итогом отображается блок «Расходы по категориям».
- Категории: Еда, Транспорт, Дом, Другое.
- Для каждой категории показывается сумма расходов за текущий месяц.
- Суммы обновляются автоматически после добавления траты.
- Данные сохраняются после обновления страницы.

## Примеры

| Расходы                           | Результат                               |
| --------------------------------- | --------------------------------------- |
| Еда — 4 000 ₸                     | Еда: 4 000 ₸                            |
| Транспорт — 50 000 ₸              | Транспорт: 50 000 ₸                     |
| Дом — 30 000 ₸                    | Дом: 30 000 ₸                           |
| Все три расхода                   | Общий итог: 84 000 ₸                    |
| Нет расходов в категории «Другое» | Другое: 0 ₸                             |
| Расход за прошлый месяц           | Не учитывается в итогах текущего месяца |

## Ограничения

- Не изменять работающую функцию добавления расходов.
- Использовать только HTML, CSS и JavaScript.
- Не подключать библиотеки.
- Деньги отображать с пробелами между тысячами.
- Не показывать NaN.
- Хранить данные только в браузере.
- Не запускать Git автоматически.

## Готово, когда

- Видны итоги по всем четырём категориям.
- Сумма по категориям совпадает с общим итогом текущего месяца.
- После добавления новой траты нужная категория обновляется сразу.
- После обновления страницы данные сохраняются.
- Расходы других месяцев не включаются в итоги текущего месяца.
- Страница удобно работает на телефоне шириной 375px.
