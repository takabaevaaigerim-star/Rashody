# Функция 001 — Добавить трату

## Для кого и зачем

Пользователь записывает ежедневные расходы, чтобы понимать, сколько денег потратил за месяц.

## Что должно быть

- Поле «Сумма, ₸».
- Выбор категории: Еда, Транспорт, Дом, Другое.
- Поле «Дата», по умолчанию сегодня.
- Поле «Комментарий», необязательное.
- Кнопка «Добавить трату».
- Список расходов, новые записи сверху.
- Общий итог за текущий месяц.
- Все расходы сохраняются в localStorage и восстанавливаются после обновления страницы.

## Примеры

| Действие                                | Ожидаемый результат                                   |
| --------------------------------------- | ----------------------------------------------------- |
| Добавить 5 000 ₸, категория «Еда»       | Запись появляется в списке                            |
| Добавить 2 500 ₸, категория «Транспорт» | Запись появляется над предыдущей                      |
| Добавить 12 000 ₸, категория «Дом»      | Общий итог за текущий месяц — 19 500 ₸                |
| Оставить сумму пустой                   | Появляется сообщение «Введите сумму»                  |
| Ввести отрицательную сумму              | Появляется сообщение об ошибке, запись не сохраняется |
| Обновить страницу                       | Все добавленные расходы остаются                      |

## Ограничения

- Использовать только HTML, CSS и JavaScript.
- Не использовать библиотеки, npm и внешние сервисы.
- Хранить данные только в браузере.
- Не показывать NaN.
- Суммы отображать в целых тенге с пробелами между тысячами.
- Не изменять другие функции без необходимости.
- Не запускать Git автоматически.

## Готово, когда

- Можно добавить трату с суммой, категорией, датой и комментарием.
- Новые траты появляются сверху списка.
- При добавлении 5 000, 2 500 и 12 000 ₸ за текущий месяц итог равен 19 500 ₸.
- Пустые, отрицательные и неверные суммы не сохраняются.
- После обновления страницы все расходы остаются.
- Страница работает на компьютере и телефоне шириной 375px.
