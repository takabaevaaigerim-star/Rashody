# Функция 004 — Бюджет по категориям

## Для кого и зачем

Пользователь хочет устанавливать отдельные месячные лимиты расходов для каждой категории, чтобы понимать, где экономит, а где превышает бюджет.

В приложении уже есть общий месячный бюджет. Новая функция дополняет его и не должна изменять существующие расчёты.

## Что должно быть

- Для категорий «Еда», «Транспорт», «Дом», «Другое» можно установить отдельный лимит на текущий месяц.
- Лимиты сохраняются в localStorage.
- Для каждой категории показываются лимит, потраченная сумма и остаток.
- При превышении лимита показывается красное предупреждение.
- Для каждой категории есть индикатор использования бюджета.
- Расходы за прошлые месяцы не учитываются в текущих итогах.
- Общий месячный бюджет продолжает работать независимо от лимитов категорий.

## Примеры

| Категория | Лимит | Потрачено | Результат |
|---|---:|---:|---|
| Еда | 15 000 ₸ | 4 000 ₸ | Осталось 11 000 ₸ |
| Транспорт | 5 000 ₸ | 7 000 ₸ | Перерасход 2 000 ₸ |
| Дом | 20 000 ₸ | 12 000 ₸ | Осталось 8 000 ₸ |
| Другое | Не установлен | 0 ₸ | Лимит не установлен |

Дополнительные проверки:
- Лимит 0 ₸ не сохраняется.
- Пустое значение не сохраняется.
- После обновления страницы установленные лимиты остаются.
- После добавления или удаления расхода остаток пересчитывается.
- При смене месяца можно установить новые лимиты. Лимиты предыдущего месяца сохраняются отдельно.

## Ограничения

- Только HTML, CSS и JavaScript.
- Без npm и внешних библиотек.
- Не изменять существующую функцию общего месячного бюджета.
- Не удалять сохранённые расходы.
- Все суммы показывать в целых тенге с пробелами между тысячами.
- Данные хранить в браузере.
- Каждый шаг реализовывать отдельно и проверять перед коммитом.
- Не выполнять Git-команды без моего разрешения.

## Готово, когда

- Пользователь может задать лимит для каждой категории.
- Лимиты сохраняются после обновления страницы.
- Расходы и остатки по категориям рассчитываются правильно.
- Перерасход отображается красным.
- Общий месячный бюджет продолжает работать.
- Все предыдущие функции приложения работают.
- Интерфейс удобен на iPhone и MacBook.
